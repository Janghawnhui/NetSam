description: 작업 마무리 — 빌드, 테스트 작성, 리뷰를 순서대로 실행
---

방금 작업한 내용을 아래 순서로 마무리해줘.

1. `dotnet build` 실행. 실패하면 여기서 멈추고 원인을 보고한다.
2. **test-writer** 서브에이전트로 새로 추가·수정된 클래스의 테스트를 작성하고 실행한다.
3. **code-reviewer** 서브에이전트로 변경 사항을 리뷰한다.
4. 결과를 한 번에 요약한다: 빌드 결과, 테스트 통과/실패 수, 🔴 항목 목록.
5. 🔴 항목이 있으면 바로 고치지 말고 수정 계획을 먼저 보여준다.

추가 지시: $ARGUMENTS
